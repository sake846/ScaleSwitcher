# Issue タイトル案

`変換操作と設定画面を共通 UI 指針に合わせて再設計する`

## 背景

copi2ctrl、ScaleSwitcher、CtrlHanabi を同じ製品群として認識できるよう、共通の情報階層、余白、タイポグラフィ、状態表現、アクセシビリティ基準を導入したい。

共通仕様は ScaleSwitcher リポジトリの `docs/ui-unification/README.md` を基準とする。この Issue では copi2ctrl の入力から結果までの流れを明確にし、結果のコピー、再実行、エラーからの復帰を迷わず行える UI を目指す。

## 着手前の確認

- [ ] 現在の入力、変換／実行、結果、コピー、設定の各 UI をキャプチャする
- [ ] 自動変換か明示実行か、クリップボードを自動更新するかなど、現在の挙動を文書化する
- [ ] 空入力、長文、変換不能、権限不足などのエラー状態を一覧化する
- [ ] UI 技術で利用できるテーマ、高コントラスト、表示倍率、アクセシビリティ API を確認する

## 目的

- 「入力 → 変換 → 結果 → コピー」の流れと現在状態を明確にする
- 他 2 アプリと同じ視覚リズムと設定画面の骨格を採用する
- 成功と失敗を色だけに頼らず伝え、次の操作を提示する
- 既存の変換結果、クリップボード動作、設定互換性を維持する

## 対象範囲

### Phase 1: UI の棚卸しとトークン導入

- [ ] 色、文字サイズ、余白、角丸、コントロール高さを共通トークン名へ対応付ける
- [ ] ハードコードされた装飾値をテーマ／スタイル定義へ集約する
- [ ] 入力、結果、設定、履歴などの領域に優先順位を付け、常時必要でない情報を折りたたむ
- [ ] 「変換」「コピー」「クリア」などの用語を画面、通知、README 間で統一する

### Phase 2: 主操作と設定画面

- [ ] 冒頭に製品名と「何をどのように変換するか」を示す 1 文を配置する
- [ ] 入力と結果を見出し、ラベル、補足で明確に区別する
- [ ] 最も頻度の高い操作（変換またはコピー）を 1 つだけ Primary action にする
- [ ] コピー成功時は短いテキストとアイコンで通知し、フォーカスや入力内容を失わない
- [ ] 入力が空など実行不能なときは主ボタンを適切に無効化し、理由を近くに示す
- [ ] 長文でも主操作が画面外へ消えないレイアウトにし、入力・結果領域のみを必要に応じてスクロールさせる
- [ ] 設定画面を「ヘッダー → 機能別セクション → フッター」に再構成する
- [ ] 即時反映ではない設定には「キャンセル」「保存」を設ける
- [ ] 設定画面の末尾に「このアプリについて」セクションを設け、製品名と実行中のプログラムバージョンを表示する
- [ ] Demod006_lora と同様に、リポジトリ直下へ 1 行形式の `version.txt` を追加し、バージョンの唯一の情報源にする
- [ ] ビルド／パッケージ作成時に `version.txt` をアプリから参照できる位置へ同梱する
- [ ] UI は起動中のアプリに同梱された `version.txt` を読み込み、前後の空白と改行を除いた値を表示する
- [ ] `version.txt` がない、空、または読み込めない場合は、例外で終了せず「不明」／`Unknown` と表示する

### Phase 3: 状態とアクセシビリティ

- [ ] `idle / editing / processing / success / error` の各状態と遷移を定義する
- [ ] 処理中の二重実行を防ぎ、進行中であることをテキストでも示す
- [ ] エラーは原因、保持された入力、再試行方法を同じ領域で示す
- [ ] 入力と結果にアクセシブルな名前を付け、結果更新を支援技術へ適切に通知する
- [ ] Tab 順を「入力 → 主操作 → 結果操作 → 補助操作」に合わせる
- [ ] ライト／ダーク、高コントラスト、100%／150%／200%、日英で確認する

## 対象外

- 変換アルゴリズムや出力仕様の変更
- ユーザーの同意なしにクリップボードへ書き込む新しい挙動
- 設定保存形式の非互換な変更
- 他 2 アプリと同じ UI 技術への移植や大型 UI ライブラリの導入

## 受け入れ条件

- [ ] 入力、結果、主操作、現在状態を視覚的・意味的に区別できる
- [ ] 空入力、処理中、成功、失敗が色だけに依存せず判別できる
- [ ] 長文および 200% 表示でも入力内容、結果、主操作へ到達できる
- [ ] コピー成功後も入力と結果が意図せず消えない
- [ ] 日本語／英語で文字切れや不要な横スクロールがない
- [ ] UI に表示されるバージョンが、配布物に同梱された `version.txt` の内容と一致する
- [ ] 開発ビルドと配布物の両方に `version.txt` が含まれている
- [ ] キーボードのみで入力、実行、結果選択、コピー、設定保存・キャンセルが完了する
- [ ] 既存の変換結果とクリップボード動作を回帰テストで確認した
- [ ] Before／After と確認条件を PR に添付する

## 実装メモ

- Web、デスクトップなど実装方式にかかわらず、可能なら OS のテーマ値を優先する。
- コピー通知にモーダルダイアログを使わず、操作を中断しないインライン表示またはライブリージョンを優先する。
- リポジトリ固有の調査結果はこの Issue に追記し、曖昧な挙動を確定してから画面を変更する。
