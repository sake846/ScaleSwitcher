# Issue タイトル案

`メイン画面と設定導線を共通 UI 指針に合わせて整理する`

## 背景

CtrlHanabi、ScaleSwitcher、copi2ctrl を同じ製品群として認識できるよう、共通の情報階層、余白、タイポグラフィ、状態表現、アクセシビリティ基準を導入したい。

共通仕様は ScaleSwitcher リポジトリの `docs/ui-unification/README.md` を基準とする。この Issue では CtrlHanabi 固有の操作を失わず、初見でも「現在の状態」「次に行う操作」「設定の入口」が分かる画面へ整理する。

## 着手前の確認

- [ ] 現在の主要画面、通知領域メニュー、ダイアログを日英・ライト／ダークでキャプチャする
- [ ] 常時表示、トレイ常駐、ショートカット中心など、最も頻度の高い利用フローを 3 件以内に整理する
- [ ] UI 技術で取得できる OS テーマ／高コントラスト／表示倍率の API を確認する
- [ ] 既存ユーザー設定と、変更してはいけないキー操作を一覧化する

## 目的

- CtrlHanabi の主操作と現在状態を最初に認識できるようにする
- 他 2 アプリと同じ視覚リズムと設定画面の骨格を採用する
- マウスだけでなくキーボードと支援技術でも完結できるようにする
- UI の整理によって既存のキー操作や常駐動作を変えない

## 対象範囲

### Phase 1: UI の棚卸しとトークン導入

- [ ] 色、文字サイズ、余白、角丸、コントロール高さを共通トークン名へ対応付ける
- [ ] ハードコードされた装飾値をテーマ／スタイル定義へ集約する
- [ ] 主操作、状態、設定、補助操作、終了操作の優先順位を決める
- [ ] 同じ意味の操作で用語、アイコン、ボタン種別が異なる箇所を統一する

### Phase 2: 主要画面と設定画面

- [ ] 主要画面の冒頭に製品名、1 文の説明、現在状態を配置する
- [ ] 最も頻度の高い操作を 1 つだけ Primary action とし、補助操作と視覚的に区別する
- [ ] 状態は色だけでなく「有効／無効」「待機中」などのテキストも併記する
- [ ] 設定画面を「ヘッダー → 機能別セクション → フッター」に再構成する
- [ ] 即時反映ではない設定には「キャンセル」「保存」を設け、未保存状態の扱いを統一する
- [ ] ショートカット入力は、現在の割り当て、競合、解除方法を同じ場所で確認できるようにする
- [ ] 危険または取り消せない操作は通常操作から離し、必要な場合のみ確認を出す
- [ ] 設定画面の末尾に「このアプリについて」セクションを設け、製品名と実行中のプログラムバージョンを表示する
- [ ] Demod006_lora と同様に、リポジトリ直下へ 1 行形式の `version.txt` を追加し、バージョンの唯一の情報源にする
- [ ] ビルド／発行時に `version.txt` をアプリから参照できる位置へ同梱する
- [ ] UI は起動中のアプリに同梱された `version.txt` を読み込み、前後の空白と改行を除いた値を表示する
- [ ] `version.txt` がない、空、または読み込めない場合は、例外で終了せず「不明」／`Unknown` と表示する

### Phase 3: フィードバックとアクセシビリティ

- [ ] 成功通知は操作を妨げず、失敗通知には原因と次の行動を含める
- [ ] 通知、OSD、トーストがある場合は共通の overlay トークンと状態用アイコンを使用する
- [ ] Tab 順を視覚順に合わせ、Space／Enter／Escape と既存ショートカットを両立させる
- [ ] 全操作要素にアクセシブルな名前・役割・状態を付ける
- [ ] ライト／ダーク、高コントラスト、100%／150%／200%、日英で確認する

## 対象外

- CtrlHanabi の中核機能や既定ショートカットの変更
- 設定保存形式の非互換な変更
- ScaleSwitcher や copi2ctrl と同じ UI 技術への移植
- 見た目だけを合わせるための大型 UI ライブラリ導入

## 受け入れ条件

- [ ] 画面を開いて 3 秒以内に現在状態と主操作を区別できる
- [ ] 設定画面の構造とボタン配置が共通指針に対応している
- [ ] 正常、無効、処理中、成功、失敗の各状態が色だけに依存せず判別できる
- [ ] 日本語／英語で文字切れやレイアウト崩れがない
- [ ] ライト／ダーク／高コントラストで操作要素とフォーカスが識別できる
- [ ] UI に表示されるバージョンが、配布物に同梱された `version.txt` の内容と一致する
- [ ] 開発ビルドと配布物の両方に `version.txt` が含まれている
- [ ] キーボードのみですべての主要操作と設定保存・キャンセルが完了する
- [ ] 既存設定を保持し、既存の主要利用フローに回帰がない
- [ ] Before／After と確認条件を PR に添付する

## 実装メモ

- 共通化の単位は UI ライブラリではなく、トークン名、階層、文言、受け入れ条件とする。
- リポジトリ固有の調査結果はこの Issue のチェック項目に追記し、推測のまま実装を始めない。
- トークン導入、画面再構成、アクセシビリティ対応は分割してレビューしてよい。
