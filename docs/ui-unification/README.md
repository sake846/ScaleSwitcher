# 3 アプリ UI 統一計画

ScaleSwitcher、CtrlHanabi、copi2ctrl の UI を、機能差を保ったまま同じ製品群として扱えるようにするための Issue 原稿です。

## 3 Issue 共通の判断軸

- **Windows ネイティブでコンパクト**: 独自デザインを強く出すより、Windows 11 の設定画面に馴染む階層、余白、操作感を優先する。
- **設定画面の骨格を統一**: ヘッダー、説明、設定セクション、フッターの順にし、主操作は右下に配置する。
- **状態を色だけで伝えない**: ラベル、チェック、アイコン、テキストを併用する。
- **OS 設定を尊重**: ライト／ダーク、高コントラスト、表示倍率、キーボード操作に追従する。
- **共通化するのは仕様**: 異なる UI 技術間でライブラリを無理に共有せず、トークン名、画面構造、文言、受け入れ基準を共有する。
- **小さく段階導入**: 各 Issue 内の Phase 1 から着手し、機能変更と見た目変更を分離する。

## 共通デザイントークン（基準値）

実装技術ごとに同等の値へ変換し、OS のテーマ値を取得できる場合は固定色よりテーマ値を優先します。

| 分類 | トークン | 基準 |
| --- | --- | --- |
| 余白 | `space-1 / 2 / 3 / 4 / 6` | `4 / 8 / 12 / 16 / 24 px` |
| 角丸 | `radius-control / card / overlay` | `4 / 8 / 12 px` |
| 文字 | `text-caption / body / title` | `12 / 14 / 20 px`、タイトルのみ Semibold |
| コントロール | `control-height` | 32 px 以上 |
| 色 | `surface / surface-alt / text / text-muted / border / accent / danger` | OS テーマ由来。ライト／ダーク両方でコントラストを確認 |
| フォーカス | `focus-ring` | キーボードフォーカスを 2 px 相当で明示 |
| 動き | `motion-fast / normal` | `100 / 200 ms`。OS の「アニメーションを表示」を尊重 |

## 共通の画面・文言ルール

1. ウィンドウタイトルは「`製品名 — 設定`」／「`Product — Settings`」。
2. 冒頭には製品名と「何を設定する画面か」を 1 文で表示する。
3. 関連項目はカードまたは区切り線でまとめ、セクション名は名詞で簡潔にする。
4. 即時反映でなければフッターを設け、右端を主ボタン、左隣をキャンセルにする。
5. 破壊的操作は通常操作から離し、必要な場合のみ確認する。
6. 無効な項目は非表示にせず無効化し、関連性を残す。必要なら理由を補足する。
7. 日本語と英語で省略やクリッピングが起きないよう、固定幅に依存しない。
8. 成功は静かな状態表示、失敗は原因と次の行動を含むメッセージで通知する。
9. 設定画面の「このアプリについて」または同等の場所から、実行中のプログラムバージョンを確認できるようにする。Demod006_lora と同様に、表示値はアプリと一緒に配布する `version.txt` から取得し、UI 内に別の固定値を持たない。

### `version.txt` の共通ルール

- リポジトリ直下の `version.txt` をバージョンの唯一の情報源とする。
- ファイルには表示するバージョンを 1 行だけ記載する（例: `1.2.3`）。読み込み時は行末の空白と改行を除去する。
- ビルド／発行時に、実行ファイルまたはアプリパッケージから参照できる位置へ `version.txt` を必ず同梱する。
- UI は起動中のアプリに同梱された `version.txt` を参照する。ソースツリーの絶対パスやカレントディレクトリには依存しない。
- ファイルがない、空、または読み込めない場合はクラッシュさせず「不明」／`Unknown` と表示する。
- リリース時に更新する場所は `version.txt` のみにし、画面文言やコードへ同じバージョンを重複定義しない。

## 横断完了条件

- [ ] 3 アプリでトークン名と設定画面の情報階層が対応している
- [ ] ライト／ダーク、100%／150%／200% 表示倍率で主要画面を確認した
- [ ] Tab、Shift+Tab、Space、Enter、Escape の操作とフォーカス順を確認した
- [ ] 日本語／英語で文言切れ、重なり、不要な横スクロールがない
- [ ] スクリーンリーダー用の名前・役割・状態が主要操作に設定されている
- [ ] 各アプリの UI からプログラムバージョンを確認でき、同梱された `version.txt` の内容と一致している
- [ ] `version.txt` がない／空／読み込めない場合もアプリが起動し、「不明」／`Unknown` と表示される
- [ ] 既存設定の読み込み・保存形式と主要機能に回帰がない
- [ ] 3 リポジトリの Before／After を同じ条件で撮影し、差分をレビューした
